TfmakeExample
--------------

TfmakeExample is a sample Terraform module project generated by TFMake.

This Terraform module accepts a message string and returns:

* original message
* reversed message
* uppercase message
* lowercase message

Installation
------------

Copy and use this module from your Terraform configuration:

```text
module "message" {
  source  = "gepeto/tfmakeexample"
  version = "0.1.0"
}
```

Usage
-----

```text
module "message" {
  source  = "gepeto/tfmakeexample"
  version = "0.1.0"
  message = "Hello Terraform"
}

output "message_original" {
  value = module.message.message_original
}

output "message_reverse" {
  value = module.message.message_reverse
}

output "message_uppercase" {
  value = module.message.message_uppercase
}

output "message_lowercase" {
  value = module.message.message_lowercase
}
```
