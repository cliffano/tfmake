# TFMake

TFMake is a Makefile for building Terraform modules.
It provides utility targets for validating, linting, documenting, and releasing Terraform modules.

Have a look at [examples/](examples/) for example projects of how TFMake can be used.

## Installation

1. Download `src/Makefile-tfmake` as the `Makefile` of your project: `curl https://raw.githubusercontent.com/cliffano/tfmake/main/src/Makefile-tfmake -o Makefile`
2. Create configuration file `tfmake.yml` with properties described in [Configuration](#configuration) section
3. Run the available `Makefile` targets described in [Usage](#usage) section

## Configuration

Create TFMake configuration file called `tfmake.yml` with contains the following properties:

| Property | Description | Example |
|----------|-------------|---------|
| package_name | The name of the Terraform module | `tfmakeexample` |
| author | The author of the module | `Some Author` |
| generator.component | The generator component type from [generator-terraform](https://github.com/cliffano/generator-terraform) | `tf-module` |
| generator.inputs.project_id | The project ID | `tfmakeexample` |
| generator.inputs.project_name | The project display name | `TfmakeExample` |
| generator.inputs.project_desc | The project description | `sample Terraform module project generated by TFMake` |
| generator.inputs.author_name | The author's name | `Some Author` |
| generator.inputs.author_email | The author's email address | `someauthor@example.com` |
| generator.inputs.author_url | The author's web site URL | `https://example.com` |
| generator.inputs.github_id | The GitHub user or organisation ID | `gepeto` |
| generator.inputs.github_repo | The GitHub repository name | `tfmakeexample` |
| generator.inputs.github_token_prefix | Prefix of GitHub token secret used by release workflows | `STUDIO` |

## Usage

The following targets are available:

| Target | Description |
|--------|-------------|
| ci | CI target to be executed by CI/CD tool, end to end build of the Terraform module |
| stage | Ensure stage directory exists |
| clean | Remove all temporary (staged, generated, cached) files |
| deps | Download TFLint, terraform-docs, and Trivy tool dependencies |
| init | Reinitialize Terraform and refresh `.terraform.lock.hcl` |
| style | Format Terraform files using `terraform fmt -recursive` |
| lint | Run `terraform validate`, TFLint, and Trivy config scan |
| test | Placeholder for future Terraform module test integration |
| doc | Regenerate the README's Terraform Doc section using [terraform-docs](https://terraform-docs.io/) |
| update-to-latest | Update Makefile to the latest version tag |
| update-to-main | Update Makefile to the main branch |
| update-to-version | Update Makefile to the version defined in `UPDATE_TARGET_VERSION` parameter |
| update-dotfiles | Update the dotfiles with latest from [generator-terraform](https://github.com/cliffano/generator-terraform) |
| update-partials | Update README partial snippets with latest from [generator-terraform](https://github.com/cliffano/generator-terraform) |
| release-major | Create a major release using [rtk](https://github.com/cliffano/rtk) |
| release-minor | Create a minor release using [rtk](https://github.com/cliffano/rtk) |
| release-patch | Create a patch release using [rtk](https://github.com/cliffano/rtk) |
